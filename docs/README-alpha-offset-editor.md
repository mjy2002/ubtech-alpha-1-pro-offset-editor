# Alpha 1 Pro — редактор оффсетов

Закрой AlphaRobot1s_QT перед запуском, подключи и включи робота, затем запусти:

```powershell
python .\alpha_offset_editor.py
```

Или двойным кликом по `run_alpha_offset_editor.cmd`.

Слева отображается схема с ID 1–16, справа — соответствующие сервоприводы и EEPROM-оффсеты.

- `+1` / `−1` сразу записывают новое значение и перечитывают его обратно;
- `Записать` позволяет ввести абсолютное значение и подтверждает запись диалогом;
- `Применить все` записывает все изменённые строки после общего подтверждения;
- перед первой записью создаётся `alpha-offsets-backup-ГГГГММДД-ЧЧММСС.json`;
- `Подключить / перечитать` заново читает все 16 значений.

Проверка связи без GUI и без записи:

```powershell
python .\alpha_offset_editor.py --check
```

Если программа пишет, что Alpha не найден, обычно открыт другой редактор, отключён USB или робот выключен. Значения не записываются автоматически при запуске.
