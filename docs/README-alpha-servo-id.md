# Экспериментальная смена ID сервопривода Alpha

Файл `alpha_servo_id_change_abobus.ino` сохранён из чата `abobus` как справочный скетч.

## Что заявлено в исходном обсуждении

- шина сервоприводов: single-wire half-duplex UART;
- предполагаемая скорость шины: 115200 baud;
- логика: 3,3 В;
- питание сервопривода: примерно 7–8 В;
- пакет начинается с `FA AF`;
- команда смены ID указана как `0xCD`.

## Важные ограничения

Скетч не проверен на этой Alpha 1 Pro. Для эксперимента нужно подключать только одну серву: если на шине несколько устройств с одним ID, можно получить конфликт или изменить не то устройство. Нельзя подключать сигнальную линию сервы напрямую к 5-вольтовому UART Arduino без согласования уровней и нельзя подавать питание сервы от вывода Arduino.

Пример пакета из обсуждения:

```text
FA AF oldId CD 00 newId 00 00 checksum ED
```

Проверять пакет и контрольную сумму перед реальной записью нужно отдельно. Для текущей Alpha 1 Pro подтверждённым остаётся USB HID-интерфейс `VID 0483 / PID 5750`; этот скетч предназначен только для дальнейшего исследования смены ID непосредственно на шине сервопривода.
